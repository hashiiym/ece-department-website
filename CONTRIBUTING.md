# Contributing to the ECE Department Website

We welcome contributions from students and faculty! To ensure the live website remains stable, please follow this branching and pull request workflow.

## How to Contribute

**1. Fork & Clone**
Fork this repository to your own GitHub account, then clone it to your local machine.

**2. Create a Branch**
Never work directly on the `main` branch. Create a new branch for your work using the following naming conventions:
* `feat/your-feature-name` (For new additions, like a new page or UI component)
* `fix/your-fix-name` (For bug fixes or layout corrections)
* `docs/your-doc-name` (For updates to text, README, or documentation)

*Example:* `git checkout -b feat/add-syllabus-section`

**3. Make Your Changes**
Ensure your code matches the existing Tailwind UI standard. 
* Do not use custom inline CSS. 
* Test your changes locally before committing.

**4. Commit & Push**
Write clear, concise commit messages explaining what you changed.
Push your branch up to your forked repository.

**5. Open a Pull Request (PR)**
Open a PR against the `main` branch of this original repository. 
* Provide a brief description of what your PR fixes or adds.
* Our Vercel integration will automatically generate a Preview Link in the comments. The maintainers will review this live preview before merging your code.

Thank you for helping improve the department's digital presence!
